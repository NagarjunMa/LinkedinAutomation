# Dark Theme Color Update

## Changes Made

### Background Color
- **Old**: Black (`#0f0e0d`)
- **New**: Dark Green (`#2c3632`)

### Color Palette Updates
- **Primary Background**: `#2c3632` (dark green)
- **Card Background**: `#2a3a35` (darker green for cards)
- **Secondary Elements**: `#3a4a45` (medium green)
- **Borders**: `#4a5a55` (lighter green for borders)

### HSL Values
- Background: `120 8% 20%` (dark green)
- Cards: `120 8% 25%` (darker green)
- Secondary: `120 8% 30%` (medium green)
- Borders: `120 8% 35%` (lighter green)

## Components Affected
- All dashboard pages (already using `bg-primary-950`)
- Layout components (already using `bg-primary-950`)
- Cards and UI components (using CSS variables)

## Orange Accent Colors
- Orange accents remain unchanged (`#ff6b35`)
- Gold accents remain unchanged (`#ffd700`)
- All accent colors work well with the new dark green background

The new color scheme provides a more sophisticated, nature-inspired look while maintaining excellent contrast and readability with the orange accent colors.
