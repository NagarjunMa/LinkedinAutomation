🧹 Clear Authentication Data

This utility will clear all authentication data from your browser to fix infinite auth loops.

What this will clear:

  • All Supabase authentication tokens
  • Session storage data
  • Authentication cookies
  • Local storage auth data

Manual Steps (if needed):

  1. Open Chrome DevTools (F12)
  2. Go to Application tab
  3. Under Storage, click "Clear storage"
  4. Check all boxes and click "Clear site data"
  5. Refresh the page
